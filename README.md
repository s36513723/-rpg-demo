# RPG Demo

ローカルで遊ぶ場合は、リポジトリ一式を同じフォルダ構成のまま保存し、ルートの `index.html` をダブルクリックして開いてください。

- `index.html`: 戦闘画面。右上の「拠点」から拠点・探索へ移動できます。
- `exploration/index.html`: 拠点・探索画面。
- HTTPサーバーは不要です。CSS・戦闘ロジック・共通ルールはHTML内にも同梱されています。
- `file://` での戦闘↔探索移動では、戦闘コンテキストをURLフラグメントでも引き継ぐため、ブラウザーごとのlocalStorage挙動に依存しません。

装備耐久・修理システムはありません。
