# 3×3 ターゲット・範囲設計

この仕様はスキルカタログ側の設計メタデータです。現時点では戦闘デモの処理そのものは変更しません。

## 盤面

前後方向は縦です。

- 味方側で画面手前にあるのは **後列**
- 中央が中列
- 敵側に近いのが前列
- 左 / 中央 / 右の3列を持つ

通常攻撃と大半の攻撃スキルは **自分の正面列** を見て、その列で最も手前にいる敵を対象にします。

同じ列に敵が1体もいない場合だけ、敵が存在する別列を選択できます。

## ターゲット規則

- **最前**: 選択された列で最も手前の敵
- **スルー**: 最前を1体飛ばし、次に存在する敵。対象が1体しかいない場合は最前へフォールバック
- **最後**: 選択された列の最後尾
- **正面**: 自分と同じ左右位置の列を使用
- **横指定**: 左 / 中央 / 右から列を選択可能

ターゲット優先順位は以下です。

1. 誘惑
2. 挑発
3. ロックオン
4. スキル固有のターゲット規則

**挑発無視**を持つスキルは挑発だけを無視します。

## 範囲

基準対象を中心に、次の6種類を使います。

- 単体
- 十字
- X字
- 縦列（前後方向）
- 横列（左右方向）
- 3×3

範囲はターゲット決定後に展開します。

## 支援範囲

複数味方への支援は原則として **使用者自身を基準** にします。

例:
- 鼓舞歌: 自分中心・横列
- 3×3支援: 自分を中心に味方陣形全体

単体支援だけは味方1人を指定します。

## 特殊規則

- **挑発**: 通常の列・最前/スルー/最後規則を上書き
- **ロックオン**: 味方側の優先対象を1体に固定。現設計では同時に1体
- **誘惑**: 次の敵対象行動を、自軍側へ向けて使用して解除
- **カウンター**: 被撃時に攻撃者へ反応。カウンターからカウンターは発生しない

## 現在の代表例

| スキル | 設計 |
|---|---|
| 毒刃 | 正面・スルー・単体 |
| 貫穿 | 正面・最前・縦列 |
| 大薙ぎ | 正面・最前・横列 |
| 狙撃 | 横指定・最後・単体・挑発無視 |
| 火球 | 横指定・最前・十字 |
| 神雷 | 横指定・最前・X字 |
| 大火炎 | 正面・最前・3×3 |
| 挑発 | 自分・挑発 |
| 精神感応 | 横指定・スルー・単体・ロックオン |
| 悪夢 | 横指定・最後・単体・誘惑 |
| 鼓舞歌 | 自分中心・横列 |

## データ項目

Activeスキルには `targeting` を持たせます。

- `side`: enemy / ally / self
- `column`: same / select / self
- `order`: front / through / last / ally / self
- `area`: single / cross / x / vertical / horizontal / 3x3
- `origin`: target / self
- `ignoreTaunt`: boolean

特殊効果は `special`、反撃系Passiveは `reaction` に保持します。
