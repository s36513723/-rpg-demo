# 敵・ボス相性設計 監査

> 現行実装の監査。ここに書く不足点は実装候補であり、未承認の数値・挙動を勝手に確定しない。

## 現在すでに成立しているもの

### 敵タイプ相性
現行 `typeAffinity()`:
- 重装 / ゴーレム / 機械: 壊弱点、斬耐性
- 飛行: 突弱点、壊耐性
- 獣: 斬弱点
- 亡者 / 死霊: 壊弱点、突耐性

これにより「敵タイプを見て物理属性を変える」基本相性は機能している。

### 配置・AI
- 弓 / 飛行など遠距離型は前列にいると後列へ下がる。
- 重装は一定周期で防御する。
- 魔術師 / 神官 / 呪術師 / 精霊 / 死霊は術を使い、周期的に詠唱付き列攻撃を行う。
- Eliteは周期的に列攻撃＋気絶を使う。
- 後列術師をスルー・狙撃・最後尾指定などで狙う戦術はプレイヤー側スキル体系と接続している。

### ボス
4地域すべてに3部位:
- arms: 主力物理技停止
- core: 全体術停止
- legs: 行動速度低下

部位ごとに弱点属性があり、破壊後は対応技を使用しなくなる。
HP 70% / 40%でフェーズが変化する。
頭封じ・腕封じなどによる行動阻止も戦闘エンジン側で処理される。

## 現在不足しているもの

### 1. 軽装タイプの固有相性
確定敵タイプには「軽装」があるが、現在 `typeAffinity()` に軽装固有ルールがない。

現状では軽装敵を見て「この武器・技を選びたい」という判断が生まれにくい。

### 2. 魔術師タイプの相性が探索戦では薄い
固定デモ敵には魔術師の弱点・耐性があるが、探索から生成する敵は `weak={}` / `resist={}` に初期化され、主に `typeAffinity()` を使う。

`typeAffinity()` には魔術師固有相性がないため、探索本編では「術師だからこの攻撃」という相性が弱い。

### 3. 獣の行動個性
獣は斬弱点を持つが、現行AIで獣専用の攻撃パターンはほぼない。
ターゲット選択に獣用の分岐はあるものの、通常攻撃は `ignoreTaunt` を持たないため、実質的な個性が出にくい。

### 4. 弓と飛行の差
弓・飛行はどちらも遠距離型として同じ後列AIに入りやすい。
飛行には突弱点があるため相性はあるが、「弓兵」と「飛行敵」で対処法や脅威がまだ十分に分かれていない。

### 5. ゴーレムと重装の差
現在は両者とも壊弱点・斬耐性の同系統。
ゴーレム固有の状態異常耐性、部位、術式、充電行動などはまだ薄い。

### 6. 4ボスの本体性能が共通
探索本編の4ボスは現在、
- HP 1280
- PHY 70 / SKL 42 / ARC 52 / MND 52
- 物防92 / 魔防84
- 壊弱点 / 斬耐性
- 同じ基本AI

を共有している。

部位名と部位弱点は地域別だが、本体の戦い方はまだ似ている。
「迷宮守護機」「辺境の巨獣」「深淵樹母」「黄金王墓の番人」を別攻略にする余地が大きい。

### 7. 敵編成シナジー
現在は個々の敵タイプの行動はあるが、
- 重装が前を塞いで後列術師を守る
- 弓兵が位置変更を強制する
- 軽装がスルーして後衛を狙う
- 術師が前衛を強化する
- 飛行が近距離攻撃を誘導する

など「組み合わせ自体が問題になる」設計はまだ弱い。

## プレイヤー側スキルと接続すべき攻略体験

1. **重装 / ゴーレム** → 壊・破甲を持ち込みたくなる。
2. **飛行** → 弓・銃・突・遠距離を使いたくなる。
3. **後列術師** → 短剣スルー、弓銃の最後尾、槍貫通などを使いたくなる。
4. **危険な大技** → 頭 / 腕封じ、部位破壊、詠唱妨害で止めたくなる。
5. **高回避軽装** → 命中補助・必中寄り・状態異常など別回答を使いたくなる。
6. **獣** → 対獣・斬だけでなく、突進や列崩しへの回答を要求する。
7. **混成編成** → 6人の武器・術法・技能を入れ替える理由を作る。

## 次の実装単位

数値を確定する前に、敵側を次の7 archetypeとして挙動レベルで分離するのが先。

- 獣
- 軽装
- 重装
- 魔術師
- 弓
- 飛行
- ゴーレム

その後、各地域に「2〜3タイプの組合せ」を定義し、同じ敵でも配置・地形で回答が変わる形にする。

ボスは共通部位システムを維持しつつ、4体それぞれに
- 固有フェーズ
- 固有大技
- 固有部位効果
- 固有状態耐性
- 固有配置干渉

を与える段階へ進める。
