# 戦闘仕様・今回の実装（schema 6）

## 防御は1行動

各キャラクターが選択するコマンドはラウンドにつき1つ。防御を選ぶと、既存の攻撃・スキル・道具予約を防御で置き換える。攻撃や道具と併用できない。

防御の軽減はコマンド入力時から有効。速度順に発動する行動ではない。別の行動を選び直すと防御を解除する。換装は行動を使わないので防御選択中も可能。条件付きの庇護・反撃・迎撃は、選択するコマンドとは別の割込みで、1人1ラウンド1回。

## Mastery

31系統のMasteryを実装済み。現行仕様は **Rank 1〜10、1 Mastery PtでRank +1、スキル習得は基本1 Pt・奥義/極意候補2 Pt**。ランタイムは正本315スキルへ切替済み。旧296はセーブ互換監査用スナップショットとしてのみ保持する。

構造として、習得条件はMasteryとPHY/SKL/ARC/MNDを参照する。源泉は1系統、術法と技能は各2系統まで取得する。数値ゲートは `spec/spec-status.json` の状態を優先する。

旧セーブの装備・所持金・探索状態・Mastery Rankは保持する。旧296にしかない習得スキルは `legacySkills` へ退避し、曖昧な名称変換をせずMastery Ptを返還する。現行315に同じキーが存在する技だけ保持する。

## 明示的なスキル定義

`skill-catalog-315.js` を正式315スキルカタログ、`rpg-rules.js` を共通ルール層として育成画面と戦闘から参照する。

各レコードにはアクティブ/パッシブ、セットCost、消費SP、依存能力、倍率、射程、範囲、状態付与、要求Rank・能力、対応装備を記録。**現行データはSPネイティブ**。MPは旧セーブ・旧スキル名を読む互換処理にだけ残し、現行スキーマへは出力しない。名前の正規表現から魔法や攻撃を推測していた戦闘変換は使用しない。

同名技を複数Masteryから習得できる場合、習得経路は複数保持する。弓・銃などの同名技が最後の定義で上書きされない。

個別値はテスト可能な初期バランス案。所要ラウンド数や最終バランスを保証するものではない。多段の倍率は全段合計。

## セットCostとパッシブ

Skill Set Capacityは **12固定**。アクティブとパッシブ共通で、能力値合計によって増加しない。

パッシブは習得しただけでは発動しない。セット中かつ必要装備を満たしたもののみ戦闘で有効。探索技能もセット中のみ。空のセットをデモ初期技で埋め戻さない。容量拡張などを外す際も、変更後のCost上限を検証する。

## 部位破壊

4地域のボスに独立した3部位HPを設定。敵情報から本体／各部位を選べる。部位への攻撃は本体HPも減らす。

| ボス | 部位 | 主な破壊結果 |
|---|---|---|
| 迷宮守護機 | 駆動腕・術式核・脚部 | 大薙ぎ停止・全体術停止・速度低下 |
| 辺境の巨獣 | 大角・喉・後肢 | 突進停止・咆哮停止・速度低下 |
| 深淵樹母 | 大蔓・花冠・根 | 蔓薙ぎ停止・瘴気術停止・速度低下 |
| 黄金王墓の番人 | 王笏・冠・脚甲 | 王撃停止・審判術停止・速度低下 |

大技の予兆は実際に予約した行動と対応する。予約後でも対応部位が壊れれば阻止。部位破壊済みの技は次の行動候補から外す。HP70%/40%で段階変化。

## 連携

異なる味方が作った条件を使う。固定のキャラクター組合せは不要。

- 引寄せ → 吹飛ばし：連携が発生する（現在の倍率+30%は初期実装値）。
- 脚封じ → 遠距離物理：連携が発生する（現在の倍率+20%は初期実装値）。
- 火 → 風：連携が発生する（現在の倍率+25%は初期実装値）。
- 追撃号令・連携舞 → 味方が弱点を突く：別の味方が追撃。

条件には期限があり、一度使うと消費。同じ本人の再使用は連携にしない。追撃も割込み上限に従い、再帰的な連鎖を発生させない。

## 召喚・詠唱・資源

使魔・死霊・式神・守護機は3ラウンド。同じ術者の再召喚は置き換えで、無制限に蓄積しない。術者が戦闘不能なら活動終了。

詠唱開始時にSPを支払い、翌ラウンドの発動では二重に支払わない。任意中止・頭封じ・気絶・睡眠による妨害を処理。通常被ダメージだけでは原則中断しない。

道具は入力時に消費・回復せず、速度順の実行時に消費。共有在庫は負数にならない。投げナイフ・鉄針・投石は携行具から投擲でき、SKL依存・1回1個消費。

回復系の一部は1戦1回。バフは同名重複せず3ラウンド、能力補正は合算で±40%まで。休息地は各層1箇所保証＋低確率で追加され、HP35%・SP35%・状態回復。休息では戦闘不能を蘇生しない。各層ボス撃破後はパーティを全回復する。

## 実行上の修正

`sheet` 変数の欠落、未セットパッシブの発動、主副セット片側だけの換装、道具の入力即時使用、召喚の未接続、蘇生対象処理、旅商人の未定義変数参照などを修正。

装備耐久・装備修理は追加していない。機巧の「修復」は味方のHP回復スキルであり、装備の修理ではない。

## 検証

`node tests/syntax.cjs` と `python tests/browser.py`。

ブラウザーテストは通常Chromium＋HTTPオリジン上で実行する。ネットワークが利用できない作業環境では `RPG_OFFLINE_TEST=1` でDOMとメモリーStorageアダプターを使う。演出待機のみ短縮し、戦闘・育成の計算処理は実装コードを使用する。

全スキルを実行するスモークテストは、各個別スキルのゲームバランスやあらゆる組合せの完全性を保証するものではない。スマートフォン実機での最終操作感、長期進行の育成速度、各地域の戦闘ラウンド数は今後のプレイ調整対象。


## 2026-09-28 正本同期

- 無手は武器なし。拳甲・手甲・ナックルは格闘武器。
- 投擲Masteryは携行具の投げナイフ・鉄針・投石・爆弾等を使用・強化し、通常装備武器としての投擲は廃止。
- 通常攻撃は武器ごとのScalingを参照し、全武器PHY固定ではない。
- 敵もPHY/SKL/ARC/MND＋技Scalingを使う。単一の敵攻撃値は正本計算値ではない。
- SP最大値は能力値から直接算出せず、現行基準100。自然回復なし、探索中持越し。
