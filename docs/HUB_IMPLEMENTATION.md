## 地域の探索

古代迷宮は封印回路、辺境遺跡は実際の迂回経路、深淵の樹海は瘴気と浄化、沈黙の砂都は熱気・日陰・清水。各層1回の仕掛けを調べられる。必須の職や道具がなくても安全策で調査できる。

各探索は3層。8テーマに対応し、各層の最後にボスを置く。各層は10〜12場所をランダム生成し、1ルートで5〜7場所を通過する。層全体の接続関係は表示するが、場所の内容は部分的に不明とする。開始時に経路・地形・イベント結果用の乱数を固定し、結果確定後にだけ次の分岐を開く。

場所では戦闘・調査・出来事・休息・旅商人・工房・強敵・宝・罠等が発生する。休息地は各層1箇所を保証し、追加休息地は低確率。休息はHP35%、SP35%と状態回復、戦闘不能は蘇生しない。各層ボス撃破後はパーティを全回復する。任意帰還は特定の帰還可能場所からのみ行える。

## 拠点の機能

道具の1/5/10個購入、素材・道具・未使用武具の売却、装備中および予備武具の誤売却防止。倉庫は武具・道具・素材・未引取の希少武具を保管。査定、引取、保管、売却、地域武具の製作、+3までの強化、特性加工を接続した。

装備候補に装備後重量と要求値を表示。主副セットの同時換装、6人の隊列、習得済みスキル検索、3組の編成プリセットを用意。プリセットは装備の所持とスキル条件を検証し、不成立なら一部だけ反映しない。防具は既存戦闘側に合わせて一式単位。戦闘用携行具と探索専用道具は区別する。

帰還時には自動回復せず、宿の「休む」でHP・SP・状態異常を全回復する。食卓では探索結果を振り返れる。探索履歴は40件保持。地域イベント・隠し地点・救助・人物・遺物・実際に観測した敵情報を閲覧できる。装備耐久・装備修理・日次作業は追加していない。

## セーブと戦闘との境界

保存キーは従来の `rpg.exploration.save1`。旧セーブの能力値、装備、習得、Mastery、所持金、開放地域を引き継ぎ、旧探索中データも移行する。自動保存・手動保存・JSON書出し・確認付き読込み・バックアップ復元・確認付き初期化に対応。壊れたデータは退避し、不正値は読込み前に検証する。

戦闘へは既存schema 6のコンテキストを渡し、現在の戦闘ページを利用する。戦闘の計算やUIは変更しない。返された結果のIDと探索IDを検証して1回だけ適用し、資源・道具消費・敵情報を受け取る。逃走は報酬なしで継続。敗北は拠点へ強制帰還して今回の探索進行を失い、使用済み道具は戻らない。獲得済みの戦利品・EXPは保持して帰還時に精算し、HP/SP/状態は宿で休むまで自動回復しない。報酬待ち・進行中地点・商人在庫・野営使用・工房使用を再読込みで保持する。

## テスト

`node tests/syntax.cjs` はJavaScript構文、重複関数、HTMLのローカル依存、既存共通スキル定義を検証する。

`tests/hub-regression.js` は132ケース。ローカルでは通常のChromium DOMとメモリーStorageアダプターで実装コードを実行し、未捕捉エラー確認1件を加えた133/133が成功した。作業環境のHTTP接続制限のため、このローカル結果をHTTPオリジン上の遷移試験とは扱わない。戦闘返却は実際の形式の結果fixtureで検証しており、戦闘デモの内部処理を代替実装したものではない。

既存のGitHub Actionsは `python tests/browser.py` によりHTTPオリジン上で同じ拠点テストと従来の戦闘テストを実行する。実行ごとの最新結果は `rpg-regression-results` アーティファクトを確認する。

機能検証は個々の選択肢・保存・資源整合の確認であり、全端末での操作感や全ビルドの長期バランス、戦闘時間を保証しない。物語・報酬・製作費は調整可能な初期コンテンツ値。

## UI20 — 宿を冒険の起点に統一

- 拠点ホームは「次にやること」と、宿・酒場 / ギルド / 市場の3施設だけを表示する。ホームからの直出撃は廃止。
- 宿・酒場はマルタの大立ち絵＋4択に統一：休む / 仲間と会話 / 酒場で会話 / 出撃準備。
- 「休む」でHP・SP・状態異常を全回復し、EXPの成長到達で発生した未精算Stat Pt / Mastery Ptを全員へ確定する。通常戦闘・強敵・ボス・探索・依頼・章報告などはEXPを与え、原則として成長ポイントを直接配布しない。
- 帰還時の自動全回復を廃止。休息と成長ポイント精算の意味を宿へ集約。
- 出撃準備は3×3陣形を中心に、各キャラの設定から装備・スキル・育成を確認し、その後に行き先を選ぶ。
- ギルドはエダを中心に、メンバー管理 / 依頼・報告 / 探索資料 / 遺物査定 / 保管庫へアクセスする。メンバー管理は登録メンバーの能力・装備・スキル・育成、陣形・出撃準備・編成プリセットへ接続する。
- 市場はバルンの大立ち絵＋4択：武具 / 道具 / 加工 / 売却。
- 保管庫はギルド、売却は市場に固定し、所持品画面からの重複ショートカットを削除。
- 噂の独立取得を廃止し、酒場でNPCと会話した結果として手掛かりが記録される。
- 下部ナビは所持品 / 記録の2つだけ。編成は宿の出撃準備から入る。
- 宿・ギルド・市場は通常サイズで縦スクロールしないことを回帰テストする。
