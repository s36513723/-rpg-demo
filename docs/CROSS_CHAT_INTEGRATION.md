## 同期済みの構造
- 6人・味方3x3、敵も基本3x3。
- HP + SP。MPは廃止。
- PHY / SKL / ARC / MND。
- Mastery Rank 1〜10、1 Mastery Pt = Rank +1。
- Skill Set Capacity 12固定、Set Cost 1〜4。
- 無手 = 武器なし。拳甲・手甲・ナックルは格闘。
- 投擲Mastery = 携行具の投擲物を使用・強化。
- 盾 = 副手。
- 武器通常攻撃属性 = 斬 / 突 / 壊の1属性。技側で上書き可能。
- 通常攻撃は武器ごとのScalingを使用。
- 敵もPHY/SKL/ARC/MND + skill Scalingを使用。
- SP最大値は能力値から直接算出しない。自然回復なし、探索中持越し。
- 距離1〜5、同一レーン最前対象、手動換装0T、自動換装なし。
- 状態異常に誘惑を含む。
- 敵タイプ7種を維持。
- 拠点は最新拠点ワークの確定UI・導線を優先。

## 2026-09-30 探索RPG×ラン構築同期
- 6人パーティで1探索3層。各層の最後にボス、第3層ボスが最終ボス。
- ダンジョンごとに固有テーマを持ち、場所・接続・遭遇はテーマ内で毎回ランダム生成する。
- 抽象的な機能ノードではなく「場所」を提示し、全ダンジョン共通の場所タイプ10種を使う。商人・宝・罠・休息・戦闘・NPC等は場所で発生する要素。
- 危険な近道／安全な迂回／宝が期待できるルート等、性格の違う分岐を作る。未選択場所は次回へ固定で残さず、次回は再生成。
- 恒久成長はStat Pt / Mastery Pt。ラン内成長は別資源のラン内スキルPt（仮称）とし、遠征終了時にリセット。戦闘資源SPとは別。
- 成功帰還時は戦利品とEXPを取得・精算。
- 敗北時は拠点へ強制帰還し、今回の探索進行を失う。獲得済み戦利品・EXPは保持して精算し、使用済み道具は戻らず、HP/SP/状態は自動回復しない。
- 1層10〜12場所生成・1ルート5〜7場所通過は初期値。


## 2026-09-30 探索ラン構造
- ラン内成長資源は Tactical Pt（TP）。Mastery/習得条件を満たす未習得スキルを、そのラン中だけ一時取得する。遠征終了でTPと一時取得をリセット。
- 各層10〜12場所をランダム生成し、1ルート5〜7場所を通過。
- 各層末にボス。撃破後はパーティ全回復。
- 各層の接続関係は全体表示、場所の内容は部分的に不明。探索技能で情報を増やす。
- 休息地は各層1箇所保証＋低確率で追加。
- 任意帰還は特定の帰還可能場所からのみ。
- 敗北は拠点へ強制帰還／探索進行消失／使用済み道具は戻らない。
