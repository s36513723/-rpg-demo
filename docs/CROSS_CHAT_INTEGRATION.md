## 同期済みの構造
- 6人・味方3x3、敵も基本3x3。
- HP + SP。MPは廃止。
- PHY / SKL / ARC / MND。
- Mastery Rank 1〜10、1 Mastery Pt = Rank +1。
- Skill Set Capacity 12固定、Set Cost 1〜4。
- 無手 = 武器なし。拳甲・手甲・ナックルは格闘。
- 投擲Mastery = 携行具の投擲物を使用・強化。
- 盾 = 副手。
- 武器通常攻撃属性 = 斬 / 突 / 壊の1属性。技側で上書き可能。
- 通常攻撃は武器ごとのScalingを使用。
- 敵もPHY/SKL/ARC/MND + skill Scalingを使用。
- SP最大値は能力値から直接算出しない。自然回復なし、探索中持越し。
- 距離1〜5、同一レーン最前対象、手動換装0T、自動換装なし。
- 状態異常に誘惑を含む。
- 敵タイプ7種を維持。
- 拠点は最新拠点ワークの確定UI・導線を優先。
