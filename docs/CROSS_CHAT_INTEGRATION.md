# 別チャット設計 統合状況 — 2026-09-28

この文書は、RPG制作プロジェクト内の別チャットで進んでいる設計を、現行GitHub実装へ安全に取り込むための作業記録。

## 反映済み

### 誘惑
- 術・スキル側では既に `誘惑` の概念とターゲット優先順位が定義されていた。
- 戦闘ランタイムへ実処理を接続。
- 誘惑中の次の敵対象行動は、自陣営へ対象が逸れる。
- 誘惑は 挑発 / ロックオン / 通常ターゲット規則より先に評価する。
- 1回分を消費したら解除する。
- UI状態アイコンにも表示。

### 7敵タイプ
現行の確定敵タイプ:
- 獣
- 軽装
- 重装
- 魔術師
- 弓
- 飛行
- ゴーレム

ランタイムで各タイプを明示分類し、共通の「前衛 / 遠距離 / 魔法」だけではなく別AIへ分離した。

現在のAI実装例:
- 獣: 高速近接、低HP狙い、飛び掛かり
- 軽装: 高速、後衛圧力、煙幕・盲目
- 重装: 高物防、防御、重打・列圧力
- 魔術師: 後列術法、周期的な詠唱攻撃
- 弓: 後列狙撃、脚封じ、挑発を無視できる狙撃
- 飛行: 後列圧力、急降下・風攻撃
- ゴーレム: 高耐久、重打・地震、猛毒/睡眠/即死への強い耐性

能力値・使用頻度・状態耐性の具体値は **初期実装値**。

### 地形別の混成遭遇
8環境それぞれに敵タイプの前列 / 後列候補を設定し、編成そのものが攻略判断になるよう変更。

例:
- 森林: 獣 / 軽装 + 弓 / 魔術師
- 洞窟: ゴーレム / 獣 + 魔術師
- 廃墟都市: 重装 / 軽装 + 魔術師 / 弓
- 山岳: 重装 / 獣 + 飛行 / 弓
- 海上・船: 軽装 / 獣 + 弓 / 飛行

具体的な出現率・能力値は **初期実装値**。

## 315スキル案

別チャットの最新設計候補として次を登録済み:
- 合計候補: 315
- 31 Mastery × Rank 1〜10 = 310基本枠
- 追加価値枠 = 5
- 武器: 15 × 10 = 150
- 防具: 3 × 10 = 30
- 源泉: 5 × 10 = 50
- 術法: 6 × 10 = 60
- 技能: 2 × 10 = 20

Rank帯の役割候補:
- Rank 1〜2: 基礎
- Rank 3〜4: 個性
- Rank 5: 中核
- Rank 6〜8: 発展
- Rank 9: 大技 / フィニッシャー
- Rank 10: Mastery完成 / 原則パッシブ候補

記録先: `spec/skill-catalog-target.json`

## まだ実装していない部分

315件の**完全な名称・Mastery・Rank対応表**は、現在取得できる別チャット履歴には残っていない。

したがって:
- 現行296件へ単純に19件を追加しない。
- 不足19件の名前を生成して埋めない。
- Rank 0〜50を機械的にRank 1〜10へ変換しない。
- 既存スキルを件数合わせで削除・統合しない。

別チャット側で正確な315件表が確定・保存された時点で、
1. 296現行実装とのID/名称差分
2. 改名
3. 統合 / 削除
4. 新規追加
5. Mastery移動
6. Rank変更
7. Set Cost / SP / 効果変更

を機械比較し、その差分だけを実装する。

## 仕様保護

`tools/check-spec-contract.mjs` で以下を検査:
- 現行runtimeは296件として記録
- 315案は要レビュー
- 315件の完全表を未取得のまま「完成」に変更しない
- 不足名称を捏造しない
- 310 + 5 = 315 の構造を維持

これにより、別チャットで設計を続けても、検討案が無断で確定仕様へ昇格しない。

## 拠点デモ最新統合

最新の拠点導線を実装へ同期:
- ホーム: 次にやること / 必要時だけ出る通知 / 次の出撃先 / 宿屋・ギルド・市場
- 宿屋: 部屋で休む / 仲間と会話 / 客と会話 / 出撃準備
- ギルド: 依頼・報告 / 探索資料 / 査定・買取 / 保管庫
- 市場: 武具 / 道具 / 加工 / 売却
- 出撃準備: 陣形 / 仲間 / 行き先
- キャラクター: 概要 / 能力値 / 装備 / スキル / 習練

ギルドの旧「メンバー管理」導線はトップ機能から外し、キャラクター管理はロスター・出撃準備・キャラクター画面へ統一。
帰還時はHP/SP/状態異常を維持し、宿の「休息する」でのみ全回復と未精算成長Pt受取を行う。
ホームは回復または未精算成長が必要な場合のみ「宿で休む」を通知する。
